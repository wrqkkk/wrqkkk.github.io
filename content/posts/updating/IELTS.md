# 1113

## Discussion-Task2 Class Size in Language Learning-1

> Some people think that language should be taught in small classes, while other people think the number of students in a language class does not matter.
> 
> Discuss both views and give your opinion.

Language learning is one of the most popular topic worldwide. On one side, people underline the size of the class. On another, it's not the main issue. My opinion is that it depends on the purpose of the learner.



It's intuitively to have the view that smaller class size helps with language learning. Since larger class means more diverse levels of vocabulary, listening and speaking, which make it harder for teachers to find a suitable teaching plan for all students. With the number of students decreasing, each student could enjoy more attention, which would definitely give them more opportunities to expose themselves. Hence, teachers could provide more focused lessons based on the feedback, making the learning process more efficient and clear.

However, unlike other subjects,language learning might be special that class size won't matter that much. What does matter is how often the learner is faced with the language using scenarios, which, as we know, require four skills: reading, listening, speaking and writing. A good language class should provide students with more opportunities to start conversations, give opinions and share perspectives using these four skills, which could hence make communication alive during class and realize the true goal of language learning.

From my point of view, it depends on the purpose of the learner. Smaller size is undoubtedly better for those who chase a higher score in exams, while teaching methods are core focus for those who want a better performance faced with a foreigner. As a conclusion, both of the opinions have their grounded reasons, and we must take more details into consideration faced with complex needs and scenarios.
